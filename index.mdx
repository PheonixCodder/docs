## What is CrossConnect-Phos?

CrossConnect-Phos is a comprehensive integration platform that centralizes metrics and synchronization jobs for multiple e-commerce marketplaces and warehouse systems. It provides a unified interface for managing data across Amazon, Walmart, Shopify, TikTok, Faire, Target, Warehance, and other platforms.

## Architecture

CrossConnect-Phos consists of two main components:

- **Backend (NestJS)** — Manages connectors, background jobs, webhooks, and data persistence with Supabase
- **Frontend (Next.js)** — Provides a multi-channel dashboard and management UI

## Technology stack

<AccordionGroup>
  <Accordion title="Backend">
    - Node.js + TypeScript + NestJS
    - BullMQ for job queues with Redis
    - Supabase for database and storage
    - nestjs-pino for structured logging
    - Optional New Relic integration
  </Accordion>
  <Accordion title="Frontend">
    - Next.js with App Router
    - React + TypeScript
    - Tailwind CSS
  </Accordion>
