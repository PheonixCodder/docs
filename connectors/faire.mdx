## Authentication

### OAuth 2.0

Faire uses OAuth 2.0 with app credentials:

**Required environment variables:**
```bash
FAIRE_APP_ID=your-app-id
FAIRE_APP_SECRET=your-app-secret
```

**Stored credentials:**
```typescript
{
  access_token: string;  // OAuth access token (encrypted)
  baseUrl?: string;      // Default: https://www.faire.com/external-api/v2
  timeout?: number;      // Default: 30000ms
}
```

### Request headers

```typescript
private get headers() {
  return {
    'X-FAIRE-APP-CREDENTIALS': Buffer.from(
      `${process.env.FAIRE_APP_ID}:${process.env.FAIRE_APP_SECRET}`
    ).toString('base64'),
    'X-FAIRE-OAUTH-ACCESS-TOKEN': this.accessToken,
    'Content-Type': 'application/json',
  };
}
```

## Service initialization

```typescript
@Injectable()
export class FaireService {
  private baseUrl: string;
  private accessToken: string;
  private timeout: number;
  private readonly maxRetries = 5;
  private readonly baseDelayMs = 500;

  constructor(
    private readonly http: HttpService,
    private readonly crypto: CryptoService,
  ) {}

  initialize(credentials: any): void {
    this.baseUrl = credentials.baseUrl || 
      'https://www.faire.com/external-api/v2';
    this.accessToken = this.crypto.decrypt(credentials.access_token);
    this.timeout = credentials.timeout || 30000;

    if (!this.accessToken) {
      throw new Error('Faire OAuth access token missing');
    }
  }
}
```

## Data synchronization

### Products

Fetches all products with automatic pagination:

```typescript
async getAllProducts(since?: string): Promise<FaireProduct[]> {
  const allProducts: FaireProduct[] = [];
  let page = 1;
  const limit = 50;

  while (true) {
    const query = new URLSearchParams({
      limit: String(limit),
      page: String(page),
    });

    if (since) {
      query.append('updated_at_min', since);
    }

    const response = await this.request<getProducts>(
      'GET',
      `/products?${query.toString()}`
    );

    if (!response?.products?.length) break;

    allProducts.push(...response.products);

    if (response.products.length < limit) break;
    page++;
  }

  return allProducts;
}
```

**Pagination logic:**
- Page size: 50 items
- Continues until fewer than 50 items returned
- Supports incremental sync with `updated_at_min`

### Inventory

Bulk inventory fetch for efficiency:

```typescript
async getInventory(
  products: Database['public']['Tables']['products']['Insert'][]
): Promise<GetInventory> {
  if (!products?.length) {
    return {};
  }

  const url = generateInventoryUrl(products);
  return this.request<GetInventory>('POST', url);
}
```

**Inventory URL generation:**

```typescript
export function generateInventoryUrl(
  products: Database['public']['Tables']['products']['Insert'][]
): string {
  const tokens = products
    .map(p => p.external_product_id)
    .filter(Boolean)
    .join(',');

  return `/products/inventory?product_tokens=${tokens}`;
}
```

## Retry logic

Implements exponential backoff with jitter:

```typescript
private async request<T>(
  method: 'GET' | 'POST' | 'PUT' | 'DELETE',
  path: string,
  params?: Record<string, unknown>,
  attempt = 0,
): Promise<T> {
  try {
    const response$ = this.http.request<T>({
      method,
      url: `${this.baseUrl}${path}`,
      headers: this.headers,
      params,
      timeout: this.timeout,
    });

    const { data } = await firstValueFrom(response$);
    return data;
  } catch (error: any) {
    const status = error?.response?.status;

    const shouldRetry = attempt < this.maxRetries &&
      (!status || status === 429 || status >= 500);

    if (!shouldRetry) {
      throw new InternalServerErrorException(
        'Failed to communicate with Faire API'
      );
    }

    // Exponential backoff with jitter
    const delay = this.baseDelayMs * 2 ** attempt +
      Math.floor(Math.random() * 250);

    this.logger.warn(
      `Retrying Faire API ${method} ${path} (attempt ${attempt + 1}) in ${delay}ms`
    );

    await this.sleep(delay);
    return this.request<T>(method, path, params, attempt + 1);
  }
}
```

**Retry parameters:**
- Max retries: 5
- Base delay: 500ms
- Jitter: 0-250ms random
- Retryable status codes: 429, 5xx

## Rate limiting

Faire API rate limits:
- **Default:** 100 requests per minute
- **Burst:** Up to 200 requests in short bursts

The connector handles rate limits via:
- Automatic retry on 429 errors
- Exponential backoff
- Request queuing in job processor

## Best practices

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication errors">
    **Error:** `401 Unauthorized`

    **Solution:**
    - Verify `FAIRE_APP_ID` and `FAIRE_APP_SECRET` are set
    - Check access token is valid and not expired
    - Ensure credentials are properly encrypted/decrypted
  </Accordion>

  <Accordion title="Empty product list">
    **Error:** No products returned

    **Solution:**
    - Verify store has products in Faire
    - Check if `updated_at_min` filter is too recent
    - Try full sync without `since` parameter
  </Accordion>

  <Accordion title="Timeout errors">
    **Error:** Request timeout

    **Solution:**
    - Increase timeout value in credentials
    - Reduce page size for pagination
    - Check network connectivity
  </Accordion>
</AccordionGroup>
