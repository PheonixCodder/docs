## Prerequisites

Before you begin, ensure you have the following installed:

- Node.js 16+ and npm
- Redis (for BullMQ job queues)
- Git

You'll also need access to a Supabase project (hosted or local).

## Get started in four steps

### Step 1: Clone the repository

Clone the CrossConnect-Phos repository to your local machine:

```bash
git clone https://github.com/PheonixCodder/CrossConnect-Phos.git
cd CrossConnect-Phos
```

### Step 2: Install dependencies

Install dependencies for both the backend and frontend:

<CodeGroup>
```bash Backend
cd backend
npm install
```

```bash Frontend
cd frontend
npm install
```
</CodeGroup>

### Step 3: Configure environment variables

Create environment files for both the backend and frontend.

<AccordionGroup>
  <Accordion icon="server" title="Backend configuration">
    Create a `backend/.env` file with the following variables:

    ```bash
    SUPABASE_URL=https://your-supabase-url.supabase.co
    SUPABASE_SERVICE_KEY=your-service-key
    CREDENTIALS_ENCRYPTION_KEY=your-64-char-hex-key
    REDIS_HOST=127.0.0.1
    REDIS_PORT=6379
    REDIS_PASSWORD=
    FRONTEND_URL=http://localhost:3000
    PORT=3001
    NODE_ENV=development
    ```

    **Generate encryption key:**
    ```bash
    node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
    ```

    <Warning>
      Never expose `SUPABASE_SERVICE_KEY` in frontend code or public repositories. This key provides full access to your database.
    </Warning>
  </Accordion>

  <Accordion icon="browser" title="Frontend configuration">
    Create a `frontend/.env.local` file with the following variables:

    ```bash
    NEXT_PUBLIC_API_URL=http://localhost:3001/api
    NEXT_PUBLIC_SUPABASE_URL=https://your-supabase-url.supabase.co
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
    ```
  </Accordion>
</AccordionGroup>

<Card title="Learn more about configuration" icon="gear" href="/configuration/environment-variables">
  View all available environment variables and their descriptions.
</Card>

### Step 4: Start the services

Start Redis, then run the backend and frontend:

<Steps>
  <Step title="Start Redis">
    Start Redis locally or using Docker:

    ```bash
    # Local Redis
    redis-server

    # Or using Docker
    docker run -p 6379:6379 redis:7
    ```
  </Step>

  <Step title="Start the backend">
    In the `backend/` directory:

    ```bash
    npm run start:dev
    ```

    The backend will start on `http://localhost:3001` (or the port specified in your `.env` file).
  </Step>

  <Step title="Start the frontend">
    In the `frontend/` directory:

    ```bash
    npm run dev
    ```

    The frontend will start on `http://localhost:3000`.
  </Step>
</Steps>

<Check>
  You should now be able to access the CrossConnect-Phos dashboard at `http://localhost:3000`!
</Check>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Redis connection errors">
    Verify that Redis is running and that `REDIS_HOST`, `REDIS_PORT`, and `REDIS_PASSWORD` are correctly set in your backend `.env` file.

    Test your Redis connection:
    ```bash
    redis-cli ping
    ```
    You should receive `PONG` as a response.
  </Accordion>

  <Accordion title="Supabase connection errors">
    Ensure your `SUPABASE_URL` and `SUPABASE_SERVICE_KEY` are valid. You can verify these in your Supabase project dashboard under Settings > API.
  </Accordion>

  <Accordion title="Port already in use">
    If port 3000 or 3001 is already in use, you can change the ports:
    - Backend: Update `PORT` in `backend/.env`
    - Frontend: Run `npm run dev -- -p 3002` to use a different port
  </Accordion>
</AccordionGroup>
